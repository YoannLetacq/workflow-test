# About

mdsite is a minimal static site generator written for the recovery benchmark.

It turns Markdown into HTML with no external dependencies — just the Python
standard library and a single HTML template.

## Why it exists

The goal is a predictable, readable build: point it at a folder of Markdown,
get a folder of HTML. No configuration, no plugins, no surprises.

## The Markdown subset

- Headings (`#` through `###`)
- **Bold** text
- [Links](https://example.com)
- Paragraphs
- Fenced code blocks
